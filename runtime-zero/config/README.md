# Configuration output contracts

Create toolchain.lock.json after a successful installation, not before. Record exact tool/backend versions, source URLs, revision or checksum, verification command/result/date and environment. Create model and workflow manifests when their tickets execute. Missing tools stay explicitly unavailable.

Keep personal absolute paths and secrets in ignored local.* files or environment variables. Commit sanitized examples after the real adapters establish their required fields. Do not add an active MCP configuration that launches a nonexistent package.
